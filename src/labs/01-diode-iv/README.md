## Фізична модель

### Діод

Струм через p–n-перехід при напрузі на переході $V_j$ (температура $T = 293$ К,
$U_T = kT/e = 25{,}25$ мВ):

$$
I_д(V_j) = I_s\left(e^{V_j/(n U_T)} - 1\right) + \frac{V_j}{R_{sh}}
\;\Big[-\,I_{bv}\, e^{-(V_j + V_{br})/(n_{bv} U_T)}\ \text{, якщо } V_j < -0{,}8\,V_{br}\Big]
$$

Напруга на виводах: $U_д = V_j + I_д R_s$. Показник експоненти обмежено 600 (`safeExp`), щоб
бісекція не отримувала `Infinity`.

### Коло стенда

`G (U₀, r = 0,5 Ом) → S1 → Rобм → амперметр (R_A) → діод`, вольтметр $R_V$ = `internalR_Ohm`
обраної межі `ANALOG_VOLTMETER` (1 кОм/В).

- **Пряме** (`Rобм = 51 Ом`, міліамперметр `ANALOG_MILLIAMMETER`): вольтметр безпосередньо на
  діоді, тому амперметр рахує $I_A = I_д + U_д/R_V$:
  $U_0 = (I_д + U_д/R_V)(R_{обм} + R_A + r) + U_д$.
- **Зворотне** (`Rобм = 10 кОм`, мікроамперметр `ANALOG_MICROAMMETER`): вольтметр на діоді разом
  із мікроамперметром: $U_V = |U_д| + |I_д| R_A$, $U_0 = (|I_д| + U_V/R_V)(R_{обм} + r) + U_V$.
- **Згорілий діод** (`open: true`) — обрив: струм тече лише через вольтметр (вольтметр показує
  майже $U_0$ — так і знаходять обрив).

Рівняння розв'язується бісекцією (`core/solve.ts`) за $V_j$: пряме — на $[0, \min(U_0, 5)]$,
зворотне — на $[-U_0, 0]$; нев'язка монотонна.

### Параметри зразків

| | VD1 (Si) | VD2 (Ge) | **X** (Si, прихований) |
|---|---|---|---|
| $I_s$ | 5·10⁻⁹ А | 1·10⁻⁶ А | 1·10⁻⁹ А |
| $n$ | 1,8 | 1,3 | 1,7 |
| $R_s$ | 0,5 Ом | 5 Ом | 2 Ом |
| $R_{sh}$ | 2·10⁸ Ом | 1·10⁶ Ом | 5·10⁸ Ом |
| Пробій | немає | $V_{br}$ = 30 В, $n_{bv}$ = 3, $I_{bv}$ = 10⁻⁶ А | немає |
| $I_{max}$ (прямий) | 100 мА | 50 мА | 100 мА |
| Зворотне обмеження | — | 0,5 мА | — |

«X» — кремнієвий діод, подібний до 1N4148/КД522, але з іншими $I_s$, $n$, $R_s$, ніж VD1:
пряма напруга й $r_д$ відрізняються від VD1 більше, ніж на допуск (перевіряється в тесті), тож
переписати відповіді VD1 не вийде.

### Еталонні відповіді кінцевого завдання (`referenceAnswers(SAMPLES.X)`)

Рахуються **тією самою процедурою, що й у студента**, на даних без шуму (`forwardVoltageAtReading`
→ покази вольтметра при заданих показах міліамперметра; `tangentFit` — той самий код, що й кнопка
на стенді):

| id | Що | Еталон | Допуск |
|---|---|---|---|
| `material` | матеріал (choice) | `Si` | — |
| `U10` | пряма напруга при I = 10 мА | 0,7073 В | ±3 % |
| `rd10` | $r_д = (U_{20} - U_5)/(20 - 5\ \text{мА})$ | 6,252 Ом | ±12 % |
| `Uopen` | $U_{відкр} = -b/k$ (необов'язково) | 0,6946 В | ±10 % |

Процедура студента для $r_д$ — хорда між 5 і 20 мА (а не сусідні точки біля 10 мА): різниця
напруг між сусідніми точками порівнянна з похибкою вольтметра (0,01 В). Для експоненти хорда
5–20 мА (з урахуванням струму вольтметра ≈ 0,7 мА, який бачить міліамперметр) дає $r_д$ з
точністю ~1–2,5 % до $nU_T/I + R_s$ при 10 мА. Моделювання 400 наборів шуму показало: з трьома
повторами в точках 5, 10, 20 мА всі відповіді потрапляють у допуск; з одним повтором $r_д$
виходить за 12 % приблизно у 3,5 % випадків — тому в тексті вимагаються повтори ×3.

## Спрощення

- Температура стала (293 К); самонагрівання діода струмом не моделюється.
- Прилади не згорають, лише зашкалюють; перевантажується тільки діод (`core/limits`:
  попередження понад $I_{max}$, згоряння понад 1,5·$I_{max}$).
- Згоряння — обрив (не коротке замикання); стан «згорів» живе лише в стані React (після
  перезавантаження сторінки діод «новий»).
- Пробій — формула з технічного завдання; через $n_{bv} U_T \approx 76$ мВ він доволі різкий:
  помітний лише в межах 29,5–30,5 В.
- **Зворотна межа джерела — 50 В, а не 40 В.** На межі 30 В вольтметр (30 кОм) разом із
  Rобм = 10 кОм утворює дільник, і на діод потрапляє лише ≈ 0,75·U₀. При 40 В напруга на VD2 не
  перевищила б ≈ 29,8 В, тобто пробій і обмеження 0,5 мА були б недосяжні. При 50 В видно
  різкий ріст струму біля 30 В (перевантаження з ≈ 45,5 В, згоряння з ≈ 48 В). Самі точки пробою
  не записуються: вольтметр на межі 30 В там уже зашкалює.
- Біля нуля стрілка не заходить за упор: від'ємні покази від шуму обрізаються до 0
  (`atZeroStop` у `Simulation.tsx`).
- Анімація струму на схемі — нормована: 40 мА (пряма гілка) і 200 мкА (зворотна) — «максимум»;
  тому зворотний струм Si (0,1 мкА) не анімується, а струм вольтметра на зворотній гілці помітно
  «переважає» струм діода (саме це пояснюється в теорії).

## Стан UI

| Стан | Значення | Примітка |
|---|---|---|
| `diodeId` | `'VD1' \| 'VD2' \| 'X'` | зміна скидає U₀ = 0 |
| `branch` | `'forward' \| 'reverse'` | це і перемикач S1, і вкладка гілки; зміна скидає U₀ = 0 |
| `U0` | 0–10 В (крок 0,05) / 0–50 В (крок 0,5) | повзунок `ParamSlider` |

| `destroyed` | `Record<SampleId, boolean>` | «липке» згоряння, скидається кнопкою «Замінити елемент» (разом з U₀) |
| `showFit` | boolean | дотична МНК для вибраного діода |

Таблиці (`useMeasurements`, 6 штук): `vlab:diode-iv:<VD1|VD2|X>:<forward|reverse>`. Рядок
`{ U, I }`: U — у В; I — у мА (пряма гілка) або в мкА, модуль (зворотна). Стовпець `Rст = U/I`
обчислюється. Шум — `useNoise('diode-iv').rngFor(<діод:гілка:U₀:межі:стан>, <PA1|PA2|PV1>)`,
після кожного запису `noise.next()`.

## Ідеї для індивідуальних варіантів

`generateVariant(r)` може випадково вибрати матеріал і параметри з реалістичних діапазонів
(`logUniform` для величин, що змінюються на порядки):

| Параметр | Si | Ge |
|---|---|---|
| `Is_A` | logUniform(5·10⁻¹⁰, 2·10⁻⁸) | logUniform(3·10⁻⁷, 5·10⁻⁶) |
| `n` | uniform(1,5; 1,95) | uniform(1,1; 1,5) |
| `Rs_Ohm` | uniform(0,3; 3) | uniform(2; 10) |
| `Rsh_Ohm` | logUniform(10⁸, 10⁹) | logUniform(3·10⁵, 3·10⁶) |
| `breakdown.Vbr_V` | немає | uniform(32; 40) — поза межею вольтметра, щоб не заважав |
| `Imax_A` | 0,1 | 0,05–0,1 (завжди > 45 мА — потрібні точки до 40 мА) |

Обмеження, які варто перевіряти при генерації (відкидати й генерувати заново):

- $U_{10}$ варіанта відрізняється від VD1/VD2 більше ніж на 5 % (інакше можна списати);
- $r_д$ варіанта відрізняється від VD1/VD2 більше ніж на 15 %;
- для Ge: $I_{зв}(20\ \text{В})$ у межах 5–80 мкА (вміщається на межі 100 мкА); для Si: < 0,5 мкА.

Допуски: матеріал — точний збіг; `U10` — ±3 %; `rd10` — ±12 % (тільки якщо в тексті вимагаються
повтори ×3, інакше краще ±15 %); `Uopen` — ±10 %. Для Ge з великим $R_s$ (≥ 8 Ом) допуск `Uopen`
варто збільшити до ±15 %: хорда через 25–40 мА відходить від дотичної сильніше.
