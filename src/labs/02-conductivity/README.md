## Фізична модель

Температура стенда $T = 293$ К (20 °C).

- $\sigma = e(n\mu_n + p\mu_p)$ — `conductivity(sample, 293)` з `src/physics/sample.ts`; $\mu(T) = \mu_{300}(T/300)^{-k}$.
- $R_4 = l/(\sigma b d)$, $R_L = L/(\sigma b d)$, $R_2 = R_L + 2R_к$.
- Джерело струму: справжній струм $I = I_\text{встан}\cdot(1 - 0{,}006)$ (`SOURCE_SETPOINT_ERR`).
  Якщо $I\,(R_2 + R_A) > 20$ В, то `inLimit = true` і $I = 20\ \text{В}/(R_2 + R_A)$, де $R_A$ — внутрішній опір DMM_DCA на обраній межі.
- Після S1 струм має знак: $I \to \pm I$.
- $U_4 = \pm I R_4 + U_\text{терм}$, $U_2 = \pm I R_2 + U_\text{терм}$. Вольтметр показує $U_4$ або $U_2$ залежно від S2.
- Покази: `readInstrument(DMM_DCA | DMM_DCV, …)` із шумом із `useNoise`.
- Розміри: $x\cdot(1 + U(-0{,}5\,\%, +0{,}5\,\%))$ заокруглюється до ціни поділки (0,05 мм — штангенциркуль, 0,01 мм — мікрометр).

### Еталонні відповіді «X» (`referenceAnswers`)

Еталон отримано процедурою студента на даних без шуму: 4-зондова схема, $I = 1…8$ мА, обидва напрямки, нахил через нуль, точні розміри, $\mu_p$ при 293 К.

| Величина | Еталон | Допуск |
|---|---|---|
| $\sigma$ | 3,038 См/м | ±5 % |
| $\rho$ | 0,3292 Ом·м (32,9 Ом·см) | ±5 % |
| $p$ | $4{,}00\cdot10^{20}$ м⁻³ ($4{,}0\cdot10^{14}$ см⁻³) | ±10 % |

Для довідки: $R_к \approx 330$ Ом. У p-Ge неосновні електрони дають поправку 0,08 % до $p = \sigma/(e\mu_p)$.

## Спрощення

- Рухливість не залежить від легування (для $N \le 10^{22}$ м⁻³ це прийнятно). Температура стала.
- Струм розподілено по перерізу рівномірно: зонди точкові, брусок довгий ($L = 2l$), поправок на геометрію немає.
- Опір вольтметра (10 МОм) не шунтує зразок. Струм через зонди і нагрівання зразка не враховано.
- Термо-ЕРС однакова для 2- і 4-зондової схем і не залежить від струму.
- Обидва контакти мають однаковий $R_к$. Опір проводів і перемикачів дорівнює нулю.
- $L$ не вимірюється на стенді: 20 мм задано в тексті.

## Стан UI

- Параметри в `useState` (не зберігаються): зразок, живлення, $I$, S1, S2, межі PA1 (20 мА) і PV1 (2 В), показ МНК.
- Незавершений рядок `pending` = `{sampleId, method, Iset, I, Up|null, Um|null}`, попередження `notice`, останній вимір розміру.
- Двокроковий запис. Перший запис (при будь-якому S1) створює `pending`: I = |показ PA1|, U₊ або U₋. Другий запис, при протилежному положенні S1, додає рядок `{I, Up, Um}` (мА, мВ, мВ; U₋ від'ємне).
  Зміна струму, зразка або S2 скасовує `pending` і показує попередження. Повторний запис тієї самої полярності заблоковано з поясненням.
- Кнопка запису неактивна, якщо: джерело вимкнене, режим «ОБМЕЖЕННЯ», OL на PA1 чи PV1 або ця полярність уже записана.
- localStorage: `vlab:conductivity:<nSi|pGe|X>:4p`, `…:2p`, `…:dims` (рядки `{b, l, d}` у мм, `null` — ще не виміряно).
- Шум: `useNoise('conductivity').rngFor('<зразок>:<схема>:<S1>:<I>:<живлення>', 'PA1'|'PV1')`. Для розмірів — `rngFor(<зразок>, 'dim', q)`. Після кожного запису чи виміру розміру викликається `noise.next()`.

## Ідеї для індивідуальних варіантів

Для `generateVariant(r)` (див. `src/core/lab.ts`) у зразка «X» можна випадково задавати:

| Параметр | Діапазон | Примітка |
|---|---|---|
| Матеріал і тип | Si/Ge × n/p (`pick`) | Для Ge тримати $N \ge 20\,n_i$ ($\ge 3\cdot10^{20}$ м⁻³), щоб $n \approx N$ з точністю < 1 % |
| $N$ | Si: $2\cdot10^{20}…5\cdot10^{21}$; Ge: $3\cdot10^{20}…5\cdot10^{21}$ м⁻³ (`logUniform`) | Не більше $10^{22}$, щоб табличне $\mu$ лишалося чинним |
| $b$, $d$ | 3,8–4,3 мм; 0,90–1,10 мм | |
| $R_к$ | 50–500 Ом | Впливає на поріг «ОБМЕЖЕННЯ» і $R_2$ |
| $U_\text{терм}$ | ±(0,05–1) мВ | |

Допуски: $\sigma$, $\rho$ — ±5 % (сумарна похибка методу ≈ 5 %), концентрація — ±10 %.

Перевірки для генератора:
- $U_4$ при 1 мА не більше 1,999 В, щоб перша точка вмістилася в межу 2 В;
- поріг обмеження $20/(R_2 + 10)$ — не менше 3 мА, щоб набралося щонайменше 6 точок;
- у відповідь додати тип (`choice`), якщо тип провідності приховано.
