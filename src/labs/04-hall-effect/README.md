## Фізична модель

Температура стенда $T = 293$ К. Константи в `model.ts`:

| Параметр | Значення |
|---|---|
| ширина зразка `SAMPLE_WIDTH_M` $b$ | 4 мм |
| відстань між зондами C–D `PROBE_DISTANCE_M` $l$ | 10 мм |
| струм зразка $I$ | 0–10 мА, крок 0,5 мА; напрям завжди «+» (від контакту 1 до 2) |
| струм магніта $I_м$ | 0–3 А, крок 0,1 А |

Формули:

- Електромагніт: `B = 0,6 Тл · tanh(I_м / 2 А) · sign(S2)` (`magnetField`). B(3 А) = 0,543 Тл, B(1,5 А) = 0,381 Тл.
- `R_H = hallCoefficient(sample, 293 K)`, `σ = conductivity(sample, 293 K)` — спільна модель
  `src/physics/sample.ts` (два типи носіїв, повна іонізація, n·p = nᵢ²).
- Напруга на холлівських контактах:
  `U_AB = R_H·I·B/d + I·δ/(σ·b·d) + U_T`.
  Перший доданок змінює знак разом з B; зсув контактів δ і термо-ЕРС U_T — ні.
- Напруга між зондами: `U_CD = I·l/(σ·b·d)` (від поля не залежить).

Умова знаків: I «+» — зліва направо, +B — від спостерігача (⊗), контакт A — верхній край.
Тоді сила Лоренца штовхає будь-які носії до A, і при I «+», +B: `U_AB > 0` ⇔ p-тип.
Модель це забезпечує автоматично, бо `U_H = R_H·I·B/d`, а R_H > 0 для p-типу.

### Зразки

| id | Назва в UI | Матеріал, тип | N, м⁻³ | d, мм | δ, мм | U_T, мкВ | R_H, м³/Кл | σ, См/м | μ_H, м²/(В·с) |
|---|---|---|---|---|---|---|---|---|---|
| `nGe` | Ge n-типу | Ge, n | 1,0·10²¹ | 0,50 | +0,10 | 40 | −6,238·10⁻³ | 65,01 | 0,4055 |
| `pGe` | Ge p-типу | Ge, p | 1,5·10²¹ | 0,60 | −0,06 | 25 | +4,157·10⁻³ | 48,26 | 0,2006 |
| `X` | Зразок «X» | **Si, p** | 2,5·10²¹ | 0,40 | +0,12 | 60 | +2,497·10⁻³ | 18,99 | 0,04740 |

Контрольні числа (I = 5 мА):

- `nGe`, B = 0,3 Т: U_H = −18,71 мВ, зсув контактів ≈ +3,85 мВ (перевірка з ТЗ: ≈ 18,8 мВ і ≈ 4 мВ).
- `X`, B = 0,381 Т (I_м = 1,5 А): U_H = +11,9 мВ, паразитна ≈ +19,8 мВ → U₁ ≈ +31,7 мВ, U₂ ≈ +7,9 мВ.
  Обидва покази додатні, U₁ більш ніж удвічі більший за U_H — без реверсу студент помиляється
  приблизно в 2,7 раза.
- `X`: U_σ = 1,646 В при 5 мА → на межі 2000 мВ «OL» настає при I > 6,0 мА (свідома пастка:
  треба зменшити струм).

### Еталонні відповіді (зразок «X»)

`referenceAnswers()` повторює процедуру студента на даних без шуму: U₁, U₂ при I = 5 мА,
I_м = 1,5 А → U_H → R_H = U_H·d/(I·B) → тип і n; U_σ при 2 мА → σ → μ = |R_H|·σ →
найближчий за рухливістю матеріал серед Si, Ge (порівняння у логарифмічній шкалі з μ_n або μ_p
за визначеним типом).

| id | Що | Еталон | Допуск |
|---|---|---|---|
| `type` | тип провідності | `p` | вибір |
| `n` | концентрація основних носіїв | 2,500·10²¹ м⁻³ | ±8 % |
| `mu` | холлівська рухливість | 0,04740 м²/(В·с) (474 см²/(В·с)) | ±10 % |
| `material` | матеріал за рухливістю | `Si` (табличні μp: Si 450, Ge 1900 см²/(В·с)) | вибір |

Пастка для матеріалу: якщо студент помилиться з типом і порівняє 474 см²/(В·с) з μn
(Si 1400, Ge 3900), жоден не збігається — це підказка перевірити знак.

## Спрощення

- Одна температура (293 К), нагрівання зразка струмом не враховано.
- Холл-фактор r = 1 (R_H = 1/(ne) точно для основних носіїв); магнітоопір відсутній, тому U_σ
  не залежить від B.
- Паразитні доданки лише ті, що не змінюють знак з B (зсув контактів, термо-ЕРС). Ефекти
  Еттінгсгаузена/Нернста (що змінюють знак з B) не моделюються — реверс поля компенсує все.
- Джерело G1 — ідеальне джерело струму; напрям струму не перемикається.
- Електромагніт без гістерезису й залишкової намагніченості; PA2 стоїть до S2 і завжди показує |I_м|.
- Товщина d відома студенту точно (з етикетки); похибку Δd = 0,01 мм він бере «з мікрометра».

## Стан UI (Simulation.tsx)

- `sampleId` (`nGe` | `pGe` | `X`), `I_mA`, `Im_A`, `s2` (1 | −1), `s3` (`'H'` | `'sigma'`),
  `series` (`vsI` | `vsB`), межі `aRange` (PA1), `cRange` (PA2), `vRange` (PV1), `showFit`.
- `pending` — незавершений рядок таблиці Холла: серія, зразок, положення регуляторів I та I_м
  у момент першого запису, I (мА), |B| (мТл), U₁/U₂ (мВ або null). Скасовується з попередженням
  (`notice`), якщо змінити I, I_м, зразок або серію. |B| береться з показу при +B.
- Таблиці: `vlab:hall-effect:<зразок>:vsI`, `…:vsB` (рядок `{I, B, U1, U2}`), `…:sigma`
  (рядок `{I, U}`). Для кожного зразка — окремі хуки з незмінними ключами (див. примітку нижче).
- Запис блокується з поясненням: I = 0; I_м = 0 (для U₁/U₂); S3 не в тому положенні;
  S2 не в тому положенні; U₁/U₂ цього рядка вже записано; OL на PA1 чи PV1; стрілка PA2 в упорі.
- Шум: `noise.rngFor('<зразок>:<I>:<I_м>:<S2>:<S3>', 'PA1' | 'PA2' | 'PT' | 'PV1')`,
  `noise.next()` після кожного запису.

Примітка: спільний `useMeasurements` при зміні `storageKey` не очищає рядки, тож якщо для нового
ключа нічого не збережено, старі рядки «перетікають» під новий ключ. Тому тут ключі сталі
(9 хуків: 3 зразки × 3 таблиці).

## Ідеї для індивідуальних варіантів

`generateVariant(r)` для зразка «X» (фіксовані b = 4 мм, l = 10 мм):

| Параметр | Діапазон | Примітка |
|---|---|---|
| матеріал | Si або Ge (`pick`) | GaAs/InSb не брати: μp GaAs ≈ μp Si — неоднозначно |
| тип | n або p (`pick`) | |
| N | 5·10²⁰–5·10²¹ м⁻³ (`logUniform`) | |
| d | 0,3–1,0 мм, крок 0,05 мм | показувати на етикетці |
| δ | ±(0,02–0,20) мм | знак випадковий |
| U_T | 10–100 мкВ | |

Обмеження, які треба перевіряти при генерації (відкидати й генерувати заново):

- |U_AB| < 199 мВ при I = 10 мА, I_м = 3 А (межа 200 мВ PV1);
- U_σ < 1,99 В хоча б при I = 3 мА (інакше мало точок для σ; для p-Si з малим N і тонким d це
  стає проблемою);
- |U_H| > 2 мВ при I = 5 мА, B = 0,38 Тл (щоб відносна похибка U_H була малою).

Допуски: n — ±8 %, μ — ±10 % (домінують ΔB/B ≈ 2,3 % і ΔI/I ≈ 1,4 % на один вимір; МНК по 6–10
точках дає фактичне відхилення 1–3 %). Тип і матеріал — точний збіг.
