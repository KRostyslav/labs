# Лаба №3 — «Ширина забороненої зони» (`band-gap`)

Дослідження температурної залежності електропровідності напівпровідників та визначення ширини
забороненої зони. Сторінка: `/labs/band-gap/`, довідник: `/labs/band-gap/dovidnyk/`.

## Фізична модель

Зразок — брусок: `l = 10 мм`, `S = 2 мм²` (`SAMPLE_LENGTH_M`, `SAMPLE_AREA_M2`).

**Напівпровідник** (спільні `src/physics/materials.ts` і `src/physics/sample.ts`):

```
Eg(T)  = Eg0 − α_V·T² / (T + β)                                  (формула Варшні)
nᵢ(T)  = nᵢ(300)·(T/300)^1,5 · exp( Eg(300)/(2k·300) − Eg(T)/(2kT) )
n      = N/2 + √((N/2)² + nᵢ²),  p = nᵢ²/n                       (n-тип, усі домішки іонізовані)
μ(T)   = μ(300)·(T/300)^(−a)                                     (Ge: aₙ = 1,66, aₚ = 2,33; Si: 2,4 / 2,2)
σ      = e·(n·μn + p·μp),   R = l / (σ·S)
```

**Метал** (локальна модель): `R = R₀·(1 + α·t)`, `t` у °C.

**Піч** (`furnaceStep`): кожні 150 мс реального часу
`t ← t + (t_ціл − t)·(1 − e^(−Δt/τ))`, `τ = 4 с`; з «Прискорити (×10)» `Δt` множиться на 10.
`t_ціл = t_зад` (піч увімкнена) або 20 °C (вимкнена). Коли `|t_ціл − t| < 0,05 °C`, температура
стає точно рівною цілі (покази перестають «плисти»). «Стабілізовано» — `|t − t_ціл| < 0,3 °C`.
Від 20 до 100 °C стабілізація займає ≈ 22 с (з прискоренням ≈ 2 с), крок 10 °C — ≈ 14 с.

**Прилади**: `THERMOMETER` (±(0,5 % + 5 од.), крок 0,1 °C) показує фактичну `t`; `DMM_OHM`
(±(0,8 % + 2 од.), 200 Ом … 20 МОм) показує `R` при фактичній `T`.

| id | Величина | Еталон | Допуск |
|---|---|---|---|
| `Eg` | Ширина забороненої зони | **1,156 еВ** | ±5 % → [1,098; 1,213] еВ |
| `material` | Матеріал | **`Si`** (найближча Eg(300 К) серед InSb, Ge, Si, GaAs) | точний збіг |

Додатково (не в `AnswerSpec`): ТКО X між 20 і 40 °C ≈ −0,031 1/К; за двома точками 100/250 °C
Eg = 1,1555 еВ. Навчальні: Ge — 0,763 еВ (60…150 °C; усі точки 20…150 °C — 0,761 еВ);
Cu — α(20 → 150 °C) = 3,96·10⁻³ 1/К (еталон `alpha`, ±5 %).

Зворотний тест (`model.test.ts`) для 5 різних «зерен» шуму знімає покази термометра й омметра
(з автопідбором межі, фактична t у межах ±0,25 °C від заданої), рахує як студент і отримує Eg
в допуску та матеріал Si.

## Нотатка для викладача: чому ефективна Eg ≠ табличній

Студент знаходить нахил `d ln R / d(1/T)`. Оскільки `R ∝ T^(m − 3/2)·exp(Eg(T)/2kT)`
(m — показник рухливості, 3/2 — з nᵢ), а `Eg(T) ≈ Eg(T*) − γ·(T − T*)` поблизу середньої
температури `T*` (γ = −dEg/dT), маємо:

```
Eg_еф = Eg(T*) + γ·T* − 2k·(m − 3/2)·T*
```

- Ge, T* ≈ 380 К: 0,632 + 0,155 − 0,025 ≈ **0,76 еВ** (модель: 0,763) — таблиця 0,66, Eg(0) = 0,744;
- Si, T* ≈ 450 К: 1,082 + 0,140 − 0,066 ≈ **1,156 еВ** (модель: 1,156) — таблиця 1,12, Eg(0) = 1,17.

Тобто нахил фактично дає Eg, лінійно екстрапольовану до 0 К, з невеликою поправкою від μ(T).
У довіднику студентам це пояснено м'яко (розділ «Чому Eg трохи відрізняється від табличного»),
з числом лише для германію — значення для кремнію там навмисно не наведено, щоб не підказувати
відповідь. Визначення матеріалу однозначне: відстані між табличними Eg значно більші за поправку.

## Спрощення

- Усі домішки іонізовані (немає «виморожування» при низьких T) — так у `sample.ts`.
- Термометр вимірює саме температуру зразка (немає градієнта в печі); шум — лише приладовий.
- Піч — ланка першого порядку без перерегулювання; при зниженні t_зад «регулятор» охолоджує з
  тією самою τ (ідеалізація). Вимкнена піч остигає до 20 °C.
- Під час зміни зразка температура печі зберігається (зразок одразу «гарячий»); t_зад
  обмежується максимумом нового зразка.
- Вимірювальний струм омметра не нагріває зразок; немає контактних опорів і термо-ЕРС.
- Мідь — лінійна модель `R₀(1 + αt)`.

## Стан UI (`Simulation.tsx`)

`sampleId`, `furnaceOn`, `setpoint` (°C), `t` (фактична, °C; початково 20 — детерміновано для
SSR), `fast` (×10), `ohmRange` (початково 20 кОм), `tab` (`rt` / `arr`), `fitFrom` (0 / 60 / 100),
`showFit`. Таблиці — `localStorage` `vlab:band-gap:Ge|Cu|X`, рядок `{ t: °C, R: Ом }`.
Ключ шуму: після стабілізації `<зразок>:<t_ціл>:stable` (покази сталі), під час зміни
температури — `<зразок>:<t з точністю 0,1>` (покази «пливуть»). Відбір точок «t ≥ …» має запас
2 °C (`FIT_SLACK_C`), щоб показ 99,7 °C при t_зад = 100 °C не випадав з прямої.

Запис заблоковано, якщо омметр показує OL або температура не стабілізувалась (з поясненням).
Підказка «можна перемкнути на меншу межу» з'являється, коли `autoRange` дає меншу межу.

## Ідеї для індивідуальних варіантів

Що можна випадково генерувати в `generateVariant(r)` (див. `src/core/lab.ts`, README → Roadmap):

| Параметр | Діапазон | Примітка |
|---|---|---|
| Матеріал X | `Si` або `Ge` | Тоді вибір матеріалу стає справжнім завданням. Для Ge: t_max = 150 °C, пряма 60…150 °C |
| Легування Si, N | 8·10¹⁵ … 1·10¹⁷ м⁻³ (log-рівномірно) | Нижче ≈ 7·10¹⁵ опір при 20 °C перевищує 19,99 МОм (OL). Eg_еф у діапазоні змінюється < 0,3 % (1,1558…1,1529 еВ) |
| Легування Ge, N | 1·10¹⁷ … 3·10¹⁸ м⁻³ | Eg_еф 0,763…0,762 еВ; при N ≥ 10¹⁹ низькотемпературні точки помітно відхиляються — корисно для завдань «чому треба t ≥ 60 °C» |
| Геометрія l, S | l = 5…15 мм, S = 1…4 мм² | Змінює лише R, не Eg. Для Si тримати `l/S ≤ 6 мм⁻¹` (інакше OL при 20 °C) |
| Метал | Cu (4,3·10⁻³), Al (4,2·10⁻³), Pt (3,9·10⁻³), Ni (6,8·10⁻³ 1/К); R₀ = 5…50 Ом | Для R₀ < 20 Ом роздільна здатність омметра обмежує точність α |
| «Вигаданий» матеріал | Eg0 = 0,9…1,4 еВ, α_V, β як у Si | Потребує окремого `Material`; перевірити, що R(20 °C) < 20 МОм і R(t_max) > 20 Ом |

Допуски: `Eg` ±5 % (еталон — та сама процедура на даних без шуму, у діапазоні з методики);
`material` — точний збіг; ТКО напівпровідника (20–40 °C) ±10 %; α металу ±10 % (при R₀ ≈ 10 Ом
похибка омметра ±0,2–0,3 Ом дає ≈ 10–15 % на інтервалі 20…150 °C).
