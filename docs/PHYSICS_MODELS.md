## Принципи

1. **Правдоподібно, але просто.** Моделі дають реальні числа (Si-діод ≈ 0,68 В при 10 мА,
   Ge ≈ 2,3 кОм у бруску 10 мм × 2 мм² при 300 К), але без складних ефектів, яких студенти
   коледжу не вивчають.
2. **Прихована істина → прилад → показ.** `simulate()` рахує точні значення, прилади додають
   похибки. Студент ніколи не бачить «істини» напряму.
3. **Еталон за процедурою студента.** `referenceAnswers()` обробляє дані без шуму тією самою
   формулою й на тому самому діапазоні точок, що й студент. Тому систематичні особливості моделі
   (напр. Eg з нахилу ln R(1/T) для Ge ≈ 0,75 еВ, а не табличні 0,66 еВ) не роблять допуск
   несправедливим.

Формули:

- Ширина забороненої зони (Варшні): `Eg(T) = Eg₀ − αT²/(T + β)`.
- Власна концентрація: `nᵢ(T) = nᵢ(300)·(T/300)^1,5·exp(Eg(300)/(2k·300) − Eg(T)/(2kT))`.
- Рухливість: `μ(T) = μ(300)·(T/300)^(−exp)`.
- Червона межа: `λ_ч = hc/Eg`.

## Зразок — `src/physics/sample.ts` (лаби 2, 3, 4)

Повна іонізація домішок, електронейтральність і `n·p = nᵢ²`:

- n-тип: `n = N/2 + √((N/2)² + nᵢ²)`, `p = nᵢ²/n` (p-тип — симетрично); власний: `n = p = nᵢ`.
- Провідність: `σ = e(n·μn + p·μp)`.
- Стала Холла (два типи носіїв): `R_H = (p·μp² − n·μn²) / (e·(p·μp + n·μn)²)` →
  для сильно легованого `R_H ≈ ∓1/(e·N)`.
- Опір бруска: `R = l/(σ·S)`.

## Прилади — `src/core/instruments.ts`, `instrumentCatalog.ts`

| Тип | Похибка Δ | Крок відліку | Перевищення межі |
|---|---|---|---|
| Стрілковий | клас · межа / 100 | ½ поділки | стрілка в упорі, «зашкалює» |
| Цифровий | a % · показ + n · (од. розряду) | межа / (counts + 1) | «OL» |

Шум показу: гаусів, СКВ = 0,3 · Δ (параметр `noiseFraction`) — три повтори різняться, але
майже завжди в межах Δ. Внутрішні опори амперметрів (`internalR_Ohm`) і вольтметрів
(1 кОм/В для стрілкових, 10 МОм для цифрових) враховуються в розрахунку кіл, де це важливо
(діод, зворотна гілка).

## Перевантаження — `src/core/limits.ts`

`overload`, якщо перевищено допустиме значення струму / напруги / потужності; `destroyed`,
якщо перевищено в 1,5 раза. «Згорілий» елемент = обрив кола до заміни.

## Обробка результатів — `src/core/stats.ts`

`mean`, `meanAbsDev` (випадкова похибка серії), `linearFit` (МНК з похибками нахилу),
`fitThroughOrigin`, `relError` (сума відносних похибок зі степенями), `roundResult`
(похибка до 1–2 значущих цифр), `withinTol` (допуск для перевірки відповідей).
